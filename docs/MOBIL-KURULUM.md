# YES Lojistik uygulaması — telefona kurulum (şoförler için)

Bu sayfayı şoförlere WhatsApp'tan gönderebilirsiniz. Kurulum 5 dakika sürer.

## 1. Uygulamayı kurun (Android)

1. Ofisin gönderdiği **APK linkine** telefondan dokunun ve dosyayı indirin.
2. "Bu kaynaktan uygulama yüklenmesine izin verilsin mi?" sorusunda **Ayarlar → İzin ver** deyin, geri dönün.
3. **Yükle**'ye dokunun. Play Koruma uyarı verirse **Yine de yükle** deyin (uygulama mağazada olmadığı için çıkar).

> iPhone için uygulama henüz mağazada değil; ofis size ayrıca haber verecek.

## 2. Giriş

- Ofisin verdiği **e-posta** ve **şifre** ile girin.
- İlk açılışta konum paylaşımıyla ilgili bir açıklama çıkar. Okuyup **Kabul ediyorum** deyin.
- Telefon konum izni sorduğunda **"Uygulamayı kullanırken"**, ardından ikinci soruda / ayarlarda **"Her zaman izin ver"** seçin.
  Aksi halde uygulama kapalıyken konum gitmez.
- Bildirim izni sorulursa **İzin ver** deyin (yeni sefer ve iptal bildirimleri için).

## 3. Pil tasarrufunu kapatın (çok önemli)

Telefonlar pil için arka plandaki uygulamaları durdurur; o zaman konum ofise gitmez. Markanıza göre:

| Marka | Yapılacak |
|---|---|
| **Samsung** | Ayarlar → Uygulamalar → YES Lojistik → Pil → **Kısıtlanmamış**. Ayrıca Ayarlar → Pil → Arka plan kullanım sınırları → "Uyuyan uygulamalar" listesinde **olmasın**. |
| **Xiaomi / Redmi / POCO** | Ayarlar → Uygulamalar → YES Lojistik → Pil tasarrufu → **Kısıtlama yok**; aynı ekranda **Otomatik başlatma** açık. |
| **Huawei / Honor** | Ayarlar → Pil → Uygulama başlatma → YES Lojistik → **Elle yönet**; üç anahtarın hepsi açık. |
| **Oppo / Realme / OnePlus** | Ayarlar → Pil → Uygulama pil yönetimi → YES Lojistik → **Arka planda çalışmaya izin ver**. |
| **Diğer** | Ayarlar → Uygulamalar → YES Lojistik → Pil → **Optimize etme / Kısıtlama yok**. |

Son uygulamalar ekranında uygulamayı **kaydırıp kapatmayın**.

## 4. Kullanım

- **Seferlerim**: size atanan seferler. Sefere dokunun.
- **Yükü Aldım → Yola Çıktım**: sırayla basın. Konum paylaşımı yük alınınca başlar, teslimde durur.
- **Teslim Ettim**: teslim ekranı açılır. Teslim alanın adını yazın, **imzasını** alın, isterseniz fotoğraf çekin ve **Teslimi Tamamla** deyin.
- **Masraf / Yakıt**: tutarı (ör. `4.450,50`), yakıtta litre ve araç km'sini yazın; **Fiş Fotoğrafı** ile fişi ekleyin. Masraf ofis onayına düşer.
- **Çekim yoksa**: yaptığınız işlem telefona kaydedilir, üstte sarı "… işlem gönderilmeyi bekliyor" şeridi çıkar.
  İnternet gelince kendiliğinden gönderilir. Şeride dokunarak bekleyenleri görebilir, **Tekrar dene** diyebilirsiniz.
- **Ofisi ara**: ana ekranın üstünde ve sefer ekranında.
- Ehliyet, SRC veya psikoteknik belgenizin süresi yaklaşınca ana ekranda uyarı görürsünüz.

## 5. Sorun olursa

- "Sunucuya ulaşılamıyor": internetinizi kontrol edin. Giriş ekranındaki **Sunucu ayarı** ofisin verdiği adres olmalı
  (varsayılan `https://yeslojistik.onrender.com`).
- Konum gitmiyorsa: 2. ve 3. adımdaki izinleri tekrar kontrol edin.
- Çıkış yaparken gönderilmemiş işlem varsa uyarı çıkar; önce internete bağlanıp gönderilmesini bekleyin.
