# Ofis / Operasyon: tek sayfa

- **Sefer aç:** Seferler → Yeni Sefer. Müşteri, araç, şoför, yükleme/teslim ili ve adresi, fiyat. Kiralık araçta taşeron otomatik gelir.
- **Kopyala:** Aynı güzergâhı tekrar mı yapıyorsunuz? Seferi açıp "Kopyala".
- **Durum:** Şoför uygulamadan ilerletir; gerekirse sefer formundan elle değiştirin.
- **Harita:** Araç Takip Haritası'nda araçların son konumu; 30 sn'de bir yenilenir.
- **Takip linki:** Sefer → "Takip linki" → WhatsApp ile müşteriye.
- **Sevk belgesi:** Sefer → "Sevk Belgesi" PDF.
- **Belgeler / bakım:** Araç kartı → Belgeler / Bakım sekmeleri. Zil simgesi süresi dolan belgeleri gösterir.
- **Arama:** Üstte "Ara" ya da Ctrl+K: plaka, müşteri, referans no.
