# Muhasebe: tek sayfa

- **Fatura kes:** Faturalar → Yeni Fatura → müşteri → teslim edilmiş seferleri seç. Ana sayfadaki "faturalanmadı" kısayolu da buraya götürür.
- **e-Fatura:** Fatura detayında e-Fatura paneli: XML indir, entegratöre yükle, "Gönderildi olarak işaretle".
- **Tahsilat:** Tahsilatlar → Tahsilat Ekle. Çek/senetse numara, banka ve vade girin; Çek/Senet sayfasından tahsil/ciro/karşılıksız.
- **Taşeron ödemesi:** Ödemeler → Ödeme Yap. Belirli bir seferin ödemesiyse seferi seçin.
- **Kasa / Banka:** Hesaplarda bakiye; kasadan bankaya yatırılan para için Virman.
- **Masraf onayı:** Giderler → "Onay bekliyor" filtresi → Onayla / Reddet (gerekçe şoföre gider).
- **Ay sonu:** Raporlar → Muhasebe Aktarımı → ayı seç → Excel ve XML ZIP'i muhasebeciye gönder.
- **Vade hatırlatma:** Müşteri sayfası → Vade Hatırlatma (e-posta ya da WhatsApp).
