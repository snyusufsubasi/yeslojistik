# Şoför: tek sayfa

1. **Kurulum:** Ofisin gönderdiği APK linkini aç, kur. Konum iznine "Her zaman izin ver" de. Pil tasarrufundan uygulamayı çıkar (bkz. MOBIL-KURULUM.md).
2. **Giriş:** Ofisin verdiği e-posta ve şifre. İlk açılışta konum açıklamasını okuyup "Kabul ediyorum".
3. **Sefer:** Seferlerim → sefere dokun. Sırayla "Yüklendi" → "Yola Çıktı" → "Teslim Ettim".
4. **Teslim:** Teslim alanın adı, imza, fotoğraf. Çekim yoksa sorun değil; uygulama internet gelince kendisi gönderir ("N işlem bekliyor").
5. **Masraf:** Seferde "Masraf Ekle": tutar, tür, fiş fotoğrafı. Ofis onaylar; reddederse gerekçe bildirim olarak gelir.
6. **Sorun:** Seferde "Ofisi ara".
