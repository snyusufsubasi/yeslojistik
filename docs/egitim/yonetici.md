# Yönetici: tek sayfa

- **Telefonda:** Aynı uygulamaya yönetici hesabıyla giriş → Özet, Seferler, Harita, Cariler, Daha.
- **Bildirimler:** Daha → Telefon bildirimleri: teslim, masraf, vadesi geçen alacak, belge süresi.
- **Onay:** Daha → Onay Bekleyen Masraflar.
- **iPhone'da panel:** Safari → panel adresi → Paylaş → Ana Ekrana Ekle.
- **Yedek:** Haftada bir Ayarlar → Veriler → "Tam yedeği indir" ve dosyayı Drive/iCloud'a kaydet. Otomatik gece yedeği ayrıca GitHub'da tutulur.
- **Kullanıcılar:** Ayarlar → Kullanıcılar: hesap aç, kilidi aç, oturumları kapat.
